# Repository Instructions

Read and follow `docs/design/code-style-guide.md` before writing or editing code. New and modified backend Java code, tests, and Java performance tools must follow its formatting conventions.

For formatting-only requests, preserve all existing behavior and unrelated working-tree changes. Do not rename, restructure, refactor, change SQL contents, or modify frontend code as part of backend formatting. Use four-space indentation, explicit control-flow braces, expanded executable bodies, separate declaration annotations, and readable multiline declarations. Validate with `./mvnw test`.
